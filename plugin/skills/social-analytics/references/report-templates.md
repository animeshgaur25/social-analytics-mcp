# Report templates

Use these when the user is making a decision about creators. Fill only with numbers from tool responses; write "n/a" rather than estimating.

## Creator comparison

```markdown
**Pick: @<handle>** — <one-sentence reason grounded in the numbers>.

| | @a | @b |
|---|---|---|
| Followers / Subscribers | | |
| Avg engagement rate (last N items) | | |
| Best format | | |
| Top item engagement | | |

- <why the winner wins>
- <where the other one is stronger, if anywhere>
- <caveat: sample size, platform differences>
```

Use the same `platform`, `post_limit` and `date_range` for every account. If accounts are on different platforms, say the engagement rates aren't directly comparable.

## Sponsorship / brand-safety vetting

```markdown
**Verdict: <Go / Go with caution / Pass>** — <one sentence>.

### Reach & engagement
<audience size, avg engagement rate vs. sample, best format>

### Audience reaction (last N items, M comments)
<positive/neutral/negative %, net score, verdict>
<1–2 representative positive and negative comments, quoted briefly>

### Risks
<recurring complaints, controversy signals, sentiment caveats>

### Recommendations
1. <format / timing / content angle for the campaign>
2. ...
```

## Single-account performance brief

```markdown
**@<handle> (<platform>)** — <headline takeaway>.

<profile summary table>
<charts>

**What's working:** ...
**What isn't:** ...
**Next 3 posts should:** ...
```
